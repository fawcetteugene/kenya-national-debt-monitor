# Kenya National Debt Monitor

Kenya National Debt Monitor is a single-page public-information dashboard that makes national-debt figures easier to explore. It presents headline balances, currency context, debt composition, trends, servicing pressure, and explanatory notes in an accessible responsive interface.

## What the dashboard provides

- A debt overview with current headline indicators and status cues
- Debt-composition and trend visualisations for at-a-glance comparison
- Currency and debt-service context to support interpretation of the totals
- Explanatory analysis panels intended for a non-specialist audience
- Responsive light/dark presentation and keyboard-friendly browser controls

## Technology

The dashboard is self-contained HTML, CSS, and JavaScript. It loads web fonts from Google Fonts and requires no build process or server.

## Run locally

Open `index.html` in a modern browser. The supplementary `indexs.html` file is retained as an alternative prototype.

## Project structure

- `index.html` — main Kenya National Debt Monitor interface
